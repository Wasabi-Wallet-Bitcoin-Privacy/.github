## What is Wasabi Wallet?

Wasabi Wallet is an open-source, non-custodial, privacy focused bitcoin wallet engineered to break transaction traceability and protect financial sovereignty. Operating as a high-performance coinjoin mixing wallet across Windows 10 and Windows 11 desktop environments, this software enables individual Bitcoin holders, security analysts, and privacy advocates to send, receive, and manage Bitcoin while preventing blockchain surveillance and address clustering.

For advanced network-level security and metadata protection, the application features native wasabi wallet tor integration that routes all network traffic through the Tor network automatically. Utilizing WabiSabi trustless multi-party transaction protocols, the software enables automated background coinjoin rounds that combine inputs from multiple users. This process obscures transaction origins without requiring trust in a centralized coordinator, ensuring users retain total control over their private keys at all times.

Beyond transaction anonymization, Wasabi Wallet provides robust coin control and blockchain synchronization tools. Users can inspect unspent transaction outputs (UTXOs) using integrated wasabi wallet utxo management features, assign specific entity labels to avoid cross-contamination, and synchronize wallet balances privately via client-side Compact Block Filters. Whether deployed via standard installation routines, operated in hardware wallet environments via ledger trezor coldcard setup, or compiled directly from wasabi wallet github repositories, Wasabi Wallet delivers a complete desktop privacy suite for modern Bitcoin management.
